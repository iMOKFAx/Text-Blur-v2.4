Install

Installation

Text Blur is a single file, TextBlur.jsx. Install it as a dockable panel, or run it once without installing.

Copy the file

Put TextBlur.jsx in the ScriptUI Panels folder:

Windows
C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Scripts\ScriptUI Panels\

macOS
/Applications/Adobe After Effects <version>/Scripts/ScriptUI Panels/

Restart After Effects

Open it from the Window menu (TextBlur.jsx) and dock it next to Effect Controls.

Allow links to open

In Preferences → Scripting & Expressions, turn on Allow Scripts to Write Files and Access Network. The tool works without it; only the social buttons will show the link to copy instead.

No install needed

Or use File → Scripts → Run Script File… and pick the file. It opens as a floating window.

How to use

Four steps

The panel has four tabs: Styles, Motion, Look and About. The action buttons stay visible below them.

Select your text

Click one or more text layers in the timeline. Text Blur works on text layers only.

Pick a style

In Styles, click a tile. Every field in Motion and Look fills in, and a short description appears under the grid.

Fine-tune (optional)

Adjust any slider in Motion or Look. Every style works as it is.

Apply

Press Apply to selected text, move the time indicator to the layer's first frame and press Space to preview.

The styles

Settings

What every setting does

Every number is a slider with its value next to it. You can also type an exact value, even beyond the slider's range. Hover any setting in the panel for the same explanation.

Motion tab

SettingRangeWhat it does
DirectionUp · From left · From right · Center out · DownWhere each word comes from. Up rises from below. From left / From right slide in sideways with a horizontal, motion-style blur (From right suits Arabic). Center out reveals the middle word first, then outward. Down falls from above.
Animate byWords · LettersEach word moves as one piece, or each letter moves on its own. With letters, use a small Stagger such as 0.02.
Delay0 – 3 sHow long to wait after the layer starts before the first word appears.
Duration0.1 – 2 sHow long one word (or letter) takes to fully appear. 0.5 is half a second.
Stagger0 – 0.3 sThe gap between one word and the next. Smaller means the line finishes faster; 0 means all at once.
Speed curvex1, y1, x2, y2A cubic-bezier easing in the same format as Flow and CSS. 0.16, 1, 0.3, 1 is a fast start with a very soft landing. A y value above 1 overshoots slightly, which reads as a bounce.
After motionNone · Slow zoom · Slow zoom out · Drift · Tracking breathe · FloatA soft extra move that starts halfway through the reveal and builds up gradually, so the line never looks frozen. Details below ↓
Motion amount0 – 20Strength of the after motion: Slow zoom and Slow zoom out 1–2 (% per second), Drift 6–14 (px per second), Tracking 2–6, Float 3–8 (px). 0 turns it off.

Look tab

SettingRangeWhat it does
Blur0 – 40How blurry each word starts; it always ends at 0. 6 is subtle, 14 is clearly visible, 25 and above feels dreamy.
Distance0 – 200 pxHow far each word travels while it appears. 0 keeps it in place.
Start scale50 – 200 %The size each word starts at. 100 is normal; 118 starts bigger and shrinks into place, as in Focus Pull.
Start tracking0 – 150Extra letter spacing at the start. 60 makes letters start apart and pull together.
Side fade width20 – 400 pxHow wide the soft fade is at each end of the line. Only used when Side fade edges is on.
Side fade edgeson / offSoftly fades the left and right ends of the line, so words glide in through a soft edge. The typical SaaS-video look.
Pop last wordon / offThe last word (or letter) lands with a small 110% → 100% scale hit. Pairs well with a colored final word.

Buttons

ButtonWhat it does
Apply to selected textAdds the reveal to every selected text layer. Applying again replaces the previous Text Blur on that layer.
Exit hereThe whole line leaves (blur and fade, in its entry direction) starting at the current time indicator. To cancel, set TB Out At (s) to −1.
RemoveRemoves everything Text Blur added. Your text itself is not changed.
After motion

Motion after the reveal

A subtle move that keeps the line alive. It doesn't wait for the last word. It starts halfway through the reveal at zero speed and eases up to full speed about a second after the text lands, so the reveal and the move read as one continuous motion.

Speed over time

Example: four words, Duration 0.5, Stagger 0.09. The reveal takes 0.77 s.

Tips

Tips and troubleshooting

For the best look

  • Use a heavy typeface such as Inter ExtraBold with tracking around −40.
  • Color the last word and turn on Pop last word.
  • Enable Motion Blur on the layer for smoother sideways moves.
  • For Arabic, use Slide RTL or From right, and animate by Words so letters stay connected.
  • For one to three words, try Center Bloom or Focus Pull.
  • For music, use Snap Pop with a Stagger that matches the beat.

If something is off

  • No motion? Move the time indicator to the layer's first frame and press Space. The reveal starts where the layer starts.
  • "Select TEXT layers"? Click a text layer in the timeline before Apply.
  • Links don't open? Turn on Allow Scripts to Write Files and Access Network.
  • Panel too tall? Drag its edge, or dock it in a wider spot.
  • Want a clean start? Press Remove, then Apply.
  • Changed the text? No need to reapply. The timing updates automatically.
